# data

시연·계산에 쓰는 자료를 모아 두는 곳입니다. 자세한 설명은 드라이브 「합성 시연 자료」 문서가 기준입니다.

| 폴더 | 내용 |
| --- | --- |
| `public/` | 공공데이터 원본 (서울시 추정매출 등) |
| `dictionary/` | 품목 사전, 메뉴 재료표 |
| `docs/` | RAG 근거 문서 (노동 규칙, 가정표, 데이터 출처) |
| `demo/` | 을지로입구 가상 카페 1곳의 합성 시연 자료 |

## 합성 시연 자료 파일

담당은 전원입니다(11.11 결정). 아래 이름은 그 숫자를 가장 잘 아는 사람이라, 값을 바꾸거나 물어볼 때 먼저 연락합니다.

| 파일 | 내용 | 잘 아는 사람 |
| --- | --- | --- |
| `dictionary/items.csv` | 품목 사전 (품목 ID·기준 단위·별칭). **가장 먼저** 채움 | 최정경 |
| `dictionary/recipes.csv` | 메뉴 재료표 (1잔에 들어가는 재료와 양) | 최정경 |
| `demo/menus.csv` | 메뉴 · 가격 · 판매 비중 | 최정경 · 최가영 |
| `demo/sales_recent.csv` | 최근 3일 메뉴별 판매 잔 수 | 최정경 |
| `demo/quotes.csv` | 거래처별 견적 (포장 단위 · 가격 · 부가세) | 최정경 |
| `demo/store.json` | 매장 이름 · 상권 · 영업시간 · 기준일 | 신준호 |
| `demo/suppliers.csv` | 거래처 최소 주문금액 · 배송비 | 신준호 |
| `demo/inventory.csv` | 재고 · 안전재고 · 보관 한도 | 신준호 |
| `demo/purchase_conditions.json` | 예산 · 배송 횟수 한도 · 계획 기간 | 신준호 |
| `demo/time_slots.csv` | 시간대 구간별 손님 비중 · 인원 | 최가영 |
| `demo/operation_conditions.json` | 하루 손님 수 · 반복 횟수 | 최가영 |
| `demo/process_times.csv` | 메뉴별 주문·제조·전달 시간, 머신 사용 시간 | 최가영 |
| `demo/staff.csv` | 직원 역할 · 시급 · 주 근무시간 | 방현식 |

이미 정해진 값은 미리 넣어 두었습니다: 시간대 손님 비중(SIM-001), 영업시간 07:00~19:00, 반복 30회.

## 채우는 규칙

- 품목 ID·단위는 `dictionary/items.csv`와 같게 씁니다.
- 단위는 g · ml · ea(개), 금액은 원, 시간은 초입니다 (COM-003).
- `source` 칸에 출처를 적고, 우리가 만든 값이면 `가정`이라고 적습니다 (COM-002).
- 모르는 값은 빈칸(JSON은 `null`), 실제로 0인 값만 0으로 적습니다 (COM-004).
- 실제 가게 이름·연락처는 넣지 않습니다. 거래처는 "거래처 A"처럼 가상 이름을 씁니다 (COM-006).
- 총필요량(`gross_need`)은 견적 정리 도구가 계산하므로 파일에 넣지 않습니다.
- 원두 예제(총필요량 2,700g · 재고 1,000g · 안전재고 500g · 1kg 포장 → 3봉, 입고 직후 4,000g, 기간 끝 1,300g)와 숫자가 맞는지 확인합니다.

## 고치는 규칙

누구나 읽고 가져다 쓸 수 있지만, 아래는 직접 고치지 않습니다. 자세한 내용은 저장소 README의 「자료·규칙 파일」을 봅니다.

- 다른 사람이 채운 자료
- `public/`의 공공데이터 원본
- `docs/`의 규칙·가정 문서
- 칸 이름 (CSV 첫 줄, JSON 키). 코드가 이 이름으로 읽습니다

고칠 일이 생기면 무엇을 왜 바꾸는지 팀에 먼저 공유합니다.
